# VietKB 0.2.5

## Mới

- Màn `Giới thiệu` hiện nhật ký thay đổi rộng hơn, dễ đọc hơn. Khung nhật ký cao gấp khoảng năm lần trước, có tiêu đề, gạch đầu dòng và chữ đậm thay vì chữ thô.
- Khi có bản cập nhật, phần `Vì sao có VietKB` tự thu gọn thành một dòng để nhường chỗ cho nhật ký. Bấm vào dòng đó để mở lại.

## Khác

- Bản phát hành được build nhanh hơn. Không thay đổi gì ở phần gõ.
