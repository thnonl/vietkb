## ALIGN items (concrete changes)

1. ALIGN-1 (row 32): AppRulesDialog on Mac: use Windows row layout (identifier column, then title) and the "Đã thêm" label. Edit `AppRulesDialog.svelte:216,223` and delete the `.app.mac` CSS at `:323-338`; keep the bundle id as stored key.
2. ALIGN-2 (row 25): Macros search shortcut keycap: render `⌘` + `F` with the same "+" separator as Windows (`Macros.svelte:295`: drop the `!platformState.mac` guard) so the hint layout matches.
3. ALIGN-3 (row 12/M4): Remove the stale "legacy charsets hidden" sentence from M4 (no UI difference exists).
4. ALIGN-4 (row 13): EN autostart label: change `quick.autostart.mac` EN to "Start with macOS" (or both platforms "Open at login"), strings.py:86, to keep the pair symmetric with VI.
5. ALIGN-5 (rows 9/35/30/31): after M9, delete mac-only CSS that no longer applies (`.v4win` radius 0, `::after` hide, `.sheet` border) unless the overlay frame needs them; run a side-by-side screenshot diff of every window (main, hotkeys, advanced, macros, about) at the same page size.
6. ALIGN-6 (row 8): Make the window title text read "Title — VietKB" like the Windows caption (`TitleBar.svelte` after M9 draws it; native `.title()` at main.rs:349/467 should be empty or equal), with the same subtitle format.

## OWNER-DECIDE questions (verbatim)

1. Q1. Tray: should a plain left-click on the menu-bar icon toggle Vietnamese on/off (right-click opens the menu), as on Windows, or open the menu (macOS convention)?
2. Q2. Hidden "Gửi chữ qua Clipboard" option: show it on Mac too (if the Mac backend can honour it), or keep it Windows-only?
3. Q3. About screen: keep the qualitative Mac line ("nhẹ và mở cửa sổ gần như tức thì") or replace it with measured Mac numbers (RAM, dmg size, open time) like Windows?
4. Q4. Default hotkeys: Mac has no default for enable, disable, app-exclude, macro panel, macro toggle. Keep that, or give Mac the same features default keys (for example the Fn-key forms or ⌃⌥ chords)?
5. Q5. Hotkey display: ⌃⌥⇧⌘ symbols run together (`⌃⇧Z`) or words (`Ctrl + Shift + Z`, with Command/Option names) as on Windows?
6. Q6. (row 29, follows Q5) Modifier error copy: glyph wording "⌃ Control, ⌥ Option, ⇧ Shift, ⌘ Command" or the Windows wording "Ctrl, Alt, Shift, Win"?
