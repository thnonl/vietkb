Why VietKB

VietKB does one job: Vietnamese typing with Telex or VNI, in Unicode. The same input method on Windows and macOS.

Free, open source, no ads. Nothing you type is recorded.

01

Features

Typing methods, text expansion and per-app rules. The same on Windows and Mac, except where noted.

  • 01

    Telex and VNI

    Pick Telex or VNI. Output is Unicode, so text pastes correctly anywhere. On Windows you can also choose decomposed Unicode (NFD).

  • 02

    Text expansion

    Keep your own list of abbreviations, and import or export it to use on another computer. It has its own on/off switch, can match capitalization, and still works with Vietnamese turned off.

  • 03

    Excluded apps

    Set rules per app. VietKB remembers whether Vietnamese was on or off in each one as you switch windows.

  • 04

    Your own shortcuts

    Turn Vietnamese on and off with Ctrl+Shift on Windows, ⌃⇧ on a Mac. Every shortcut can be changed in Settings. See the defaults.

  • 05

    Small

    On Windows: 14 MB while running in the tray, and a 3.1 MB installer. On Mac: one .dmg for both Apple silicon and Intel. Built with Rust and Tauri 2.

  • 06

    Tray and menu bar

    Windows: left-click the V/E icon in the tray to switch. Mac: click V/E in the menu bar to open its menu. Open at login, start hidden, and check for updates from inside the app.

  • 07

    Accurate typing

    Old- or new-style tone marks, free tone placement, spell check, and restore misspelled words. Also auto-capitalized sentences, j/f/w/z as consonants, and ưo corrected to ươ.

  • 08

    Raw text zones

    Mark URLs or code so VietKB leaves them exactly as typed.

  • 09

    Password fields left alone

    In password fields, keys come through exactly as pressed, with no tone marks. On Windows, VietKB also types Vietnamese on the on-screen keyboard.

  • 10

    Status sounds

    Two distinct sounds tell you when Vietnamese turns on and off.

04

Install

Three steps on each platform. Nothing else to install.

On Windows

  1. 1

    Download the installer

    Click Download for Windows and get the latest .exe from the release page.

  2. 2

    Run it

    Open the file and follow the installer. When it finishes, VietKB sits in the system tray, ready to type.

  3. 3

    Start typing

    Type in any text field. Left-click the tray icon to turn Vietnamese off or back on.

Windows SmartScreen may warn you The installer is not code-signed yet, so SmartScreen may show a warning. Choose More info, then Run anyway. The source code is on GitHub.

On macOS

  1. 1

    Drag to Applications

    Click Download for macOS and get VietKB_…_universal.dmg. Open it and drag VietKB into Applications.

  2. 2

    Open it the first time

    In Applications, right-click VietKB, choose Open, then Open again. You only do this once. If macOS still blocks it, see the note below.

  3. 3

    Allow Accessibility

    The settings window shows a yellow banner. Click its button, then turn on VietKB under Privacy & Security > Accessibility. Once the V shows in the menu bar, you can type.

macOS says VietKB can’t be opened The Mac version is not notarized by Apple yet. If right-click › Open doesn’t help, go to System Settings > Privacy & Security, scroll down and click Open Anyway. Or run this in Terminal: 

xattr -dr com.apple.quarantine /Applications/VietKB.app

Turn off other Vietnamese input methods first Two input methods running at once produce garbled text. Quit EVKey, OpenKey or Unikey. On a Mac, switch the input source to ABC instead of the built-in Vietnamese input.

05

FAQ

Common questions, especially right after installing on a Mac.

macOS says “VietKB can’t be opened”. What now?

The Mac version is not notarized by Apple yet, so macOS blocks the first launch. Right-click VietKB in Applications and choose Open. If it is still blocked, go to System Settings > Privacy & Security and click Open Anyway. You only need to do this once per install.

Why does VietKB need Accessibility access?

To see the keys you press and replace them with Vietnamese letters. Without it, macOS lets no input method do that. VietKB records nothing you type and sends nothing anywhere.

Accessibility is on, but VietKB still asks for it?

This usually happens after installing a new version over the old one. Turn the VietKB switch under Accessibility off and on again. If that doesn’t work, remove VietKB from the list with the − button and open VietKB again.

Why don’t tone marks appear in password fields?

That is on purpose. Password and other secure fields get exactly the keys you press, so a password never turns into accented letters.

Does the Mac version update itself?

Not yet. VietKB tells you when a new version is out and opens the download page. Download the new .dmg and drag it over the old copy in Applications. Self-updating needs an Apple-notarized build, so it isn’t available yet. The Windows version updates itself from inside the app.

Can I use it alongside the Vietnamese input built into macOS?

Not at the same time. While using VietKB, pick ABC as the input source in the menu bar. To go back to the macOS input, quit VietKB first.

On a Mac, F1 and F2 don’t switch Vietnamese?

On a Mac the F keys control brightness and volume, so VietKB leaves them unassigned. Use ⌃⇧ (Control + Shift), or set your own keys under Shortcuts…

Why does VietKB come and go in the Dock?

VietKB shows in the Dock while one of its windows is open. Close the window and it keeps running, with just the V/E icon in the menu bar.
