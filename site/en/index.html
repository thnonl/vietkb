  2. 2

  3. 3

Why VietKB

VietKB is a small Vietnamese keyboard that works the same way on Windows and Mac. Install it, set a few options, and get on with your typing.

VietKB is free and open source. It does not store or send anything you type. Details are in the privacy policy.

Features

Everything below works on both Windows and Mac, unless noted.

  • 01 Highlight

    Recognize English and code

    English words, names, file names and code typed in Vietnamese text stay as you typed them, with no doubled keys and no switching Vietnamese off. Over 95% of the 10,000 most common English words are kept as typed. Vietnamese barely changes: 2 of nearly 4,700 common words. Press Ctrl+Shift+Z (Mac: ⌃⇧Z) to switch back.

    Tested with Telex on the 10,000 most common English words, 200 file names and code snippets, and 4,694 common Vietnamese words. The word list keeps growing with every update.

  • 02

    Telex and VNI

    Choose Telex or VNI, and old-style (hoà) or new-style (hòa) tone placement. Text comes out as precomposed Unicode. On Windows you can also pick decomposed Unicode (NFD).

  • 03

    Text expansion

    Set your own abbreviations, for example vn for Việt Nam. Export the list to a file to take it to another computer. Expansion can keep working while Vietnamese is off.

  • 04

    Per-app settings

    Keep Vietnamese off in games or the terminal, or use a different typing method in one app. VietKB can also remember whether you had Vietnamese on or off in each app.

  • 05

    Shortcuts

    Press Ctrl+Shift (Windows) or ⌃⇧ (Mac) to turn Vietnamese on or off. Change the keys in the Shortcuts… window. See all shortcuts.

  • 06

    Small

    The Windows installer is only 3.1 MB, and the app uses less than 5 MB of RAM in the background (as Task Manager shows it). The Mac version is one .dmg for both Apple silicon and Intel.

  • 07

    The V/E icon

    The icon in the tray (Windows) or the menu bar (Mac) shows whether you are typing Vietnamese (V) or English (E). Click it to switch, right-click for the menu. When an update is out, the icon shows a dot.

  • 08

    Capitals and vowel fixes

    It can also capitalize new sentences and fix ưo to ươ.

  • 09

    Web and email addresses

    When you type a web address, an email address or a file path, VietKB adds no tone marks to it.

  • 10

    Passwords, on-screen keyboard

    In password fields, every key comes through as pressed, with no tone marks. On Windows, the system on-screen keyboard types Vietnamese too.

  • 11

    Sounds

    If you like, VietKB plays one sound when Vietnamese turns on and another when it turns off.

Default shortcuts

On a Mac, F1, F2, F8, F9 and F11 control brightness, volume and Show Desktop, so VietKB leaves those actions unassigned. In the Shortcuts… window you can change the keys for Vietnamese on/off, Change typing method, Restore misspelled word and Open settings.

Interface

The settings window holds the options you use most. Shortcuts, abbreviations and advanced options have windows of their own. The title bar has a VI | EN button for the language and a Light/Dark button. By default the look follows the system. The screenshots show the Vietnamese interface.

Install

Three steps on each computer. Nothing else to install.

On Windows

  1. 1

    Download the installer

    We recommend getting it from Microsoft Store: it installs and updates automatically, with no unsigned-app warning. Or click Download for Windows to use the .exe installer. On Windows on Arm (Snapdragon), use the ARM64 installer; on 32-bit Windows, the x86 installer.

  2. 2

    Install

    Open the file and click through the installer. When it finishes, the V/E icon appears in the system tray.

  3. 3

    Start typing

    Open Notepad or any text field and type. Click the V/E icon to turn Vietnamese on or off.

If Windows shows a SmartScreen warning The .exe from GitHub is not code-signed yet, so Windows may warn you. Click More info, then Run anyway. The Microsoft Store version does not show this warning.

On macOS

  1. 1

    Download

    Click Download for macOS, open the .dmg and drag VietKB into Applications.

  2. 2

    Open it the first time

    In Applications, right-click VietKB, choose Open, then click Open again in the dialog. You only do this the first time. If macOS still blocks it, see the note below.

  3. 3

    Allow access

    VietKB needs Accessibility and Input Monitoring access to type. Click Allow access… on the yellow banner in the settings window, then turn on VietKB in both lists under Privacy & Security. It types as soon as both are on.

If macOS won’t open VietKB The Mac version is not notarized by Apple yet. Go to System Settings > Privacy & Security, scroll down and click Open Anyway. Or run this in Terminal: 

xattr -dr com.apple.quarantine /Applications/VietKB.app

Turn off other Vietnamese keyboards first If EVKey, OpenKey or Unikey is running, quit it first. Two Vietnamese keyboards at once garble your text. On a Mac, set the input source to ABC instead of the built-in Vietnamese input.

FAQ

Most of these come up right after installing on a Mac.

I use Unikey, EVKey or OpenKey. Can I switch to VietKB?

Yes. VietKB is a Vietnamese keyboard for Windows and macOS. It types Telex or VNI in Unicode, so you type the way you did with Unikey, EVKey, OpenKey, GoTiengViet, Vietkey or WinVNKey. Quit your old keyboard before you start VietKB, because two Vietnamese keyboards at once garble your text. VietKB is a separate project and is not affiliated with any of them.

macOS says “VietKB can’t be opened”. What now?

The Mac version is not notarized by Apple yet, so macOS blocks the first launch. Right-click VietKB in Applications and choose Open. If it is still blocked, go to System Settings > Privacy & Security and click Open Anyway.

Why does VietKB need Accessibility and Input Monitoring?

On a Mac, any Vietnamese keyboard needs both to read the keys you press and replace them with accented letters. VietKB does not store or send anything you type.

Accessibility is on, but VietKB still asks for it?

This usually happens after installing a new version over the old one. Turn the VietKB switch under Accessibility and Input Monitoring off and on again. If that doesn’t work, remove VietKB from the list with the − button and open VietKB again.

Why don’t tone marks appear in password fields?

On purpose. VietKB adds no tone marks in password fields, so your password is always exactly the keys you pressed.

Does the Mac version update itself?

Not yet. When a new version is out, the menu bar icon shows a dot; click it to open the download page. Download the new .dmg and drag it over the old copy in Applications. The Windows version updates itself from inside the app.

Can I use it alongside the Vietnamese input built into macOS?

Not at the same time. While using VietKB, pick ABC as the input source in the menu bar. To go back to the macOS input, quit VietKB first.

Why don’t F1 and F2 switch Vietnamese on a Mac?

On a Mac the F keys control brightness and volume, so VietKB leaves them alone. Press ⌃⇧ (Control + Shift), or pick another key in the Shortcuts… window.

Is VietKB available in English?

Yes. Click VI | EN in the title bar to switch the language. No restart needed.

Why does VietKB come and go in the Dock?

VietKB shows in the Dock only while one of its windows is open. Close the window and it keeps running, with just the V/E icon in the menu bar.
