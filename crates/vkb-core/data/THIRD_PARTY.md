# Third-party data in `vkb-core/data` (D10, 0.2.8)

VietKB is MIT. Everything here is either written for VietKB or derived from
sources under permissive terms. No data is fetched at run time: the files are
generated once by `scripts/gen_wordlists.py` and embedded in the binary.

| file | what | derived from | licence |
|---|---|---|---|
| `english.txt` | English words (levels 1-7) that Telex composes into something else, about 3,100 words | SCOWL 2020.12.07 `english-words.10 … .60` + `scripts/wordlists/tech-words.txt` + `loanwords.txt` | SCOWL licence (below); the two small lists are written for VietKB (MIT) |
| `vi.txt` | Vietnamese syllables and how often they occur (about 4,000 syllables seen at least once, impossible rimes removed) | syllable counts over Tatoeba Vietnamese sentences and the Common Voice Vietnamese sentence list | counts only, see below |
| `bigrams.rs` | sorted 32-bit hashes of word pairs for the D10 two-sided rule: English pairs (about 6,300) and Vietnamese syllable pairs (about 8,600), each pair containing an ambiguous word (`max`, `box`, `room` ...) | Tatoeba English sentences (`eng_sentences_detailed.tsv`), Tatoeba Vietnamese sentences, Common Voice Vietnamese `sentence-collector.txt`; generated by `scripts/gen_bigrams.py` | hashes only, see below |
| `real_syllables.rs` | 165 Vietnamese syllable keys that the corpus does not attest but standard words use (D10, 0.2.9), hand-curated; the reviewed not-real list is `tests/fixtures/d10_not_vietnamese.txt` | written for VietKB by hand | MIT |
| `consts.rs` | the generated prefix table of Vietnamese rimes, totals | `vi.txt` corpus rimes, curated by `rimes-extra.txt` / `rimes-drop.txt` | counts only |

No sentence and no word sequence is stored: only how often each syllable occurs, and (`bigrams.rs`) one-way hashes of word pairs that contain an ambiguous word.

The full notices (SCOWL copyright verbatim, Tatoeba credit and licence, Common Voice) are in
[`THIRD_PARTY_NOTICES.md`](../../../THIRD_PARTY_NOTICES.md) at the repository root; that file is bundled with the app.
Regenerate the data with `python3 scripts/gen_wordlists.py` (see the script's docstring).
